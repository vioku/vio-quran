# Vio Qur'an

Aplikasi web **Al-Quran, Doa Harian & Dzikir** — modern, mobile-friendly, dengan gaya Neobrutalism UI.

**Demo:** [vioku.github.io/vio-quran](https://vioku.github.io/vio-quran)

---

## Stack

| Bagian | Teknologi |
|---|---|
| **Framework** | React 19 |
| **Router** | React Router 7 |
| **Build Tool** | Vite 8 |
| **Audio Player** | react-h5-audio-player |
| **Font** | Space Grotesk + Noto Naskh Arabic |
| **Style** | Neobrutalism UI (pure CSS) |
| **Deploy** | GitHub Pages |

## Fitur

- Baca Al-Quran lengkap 114 surah
- Audio murrotal per surah
- Doa harian & dzikir
- Markah favorit (Al-Quran & Doa)
- Pencarian surah & doa
- Navigasi surah prev/next
- Neobrutalism UI — bold border, hard shadow, vibrant colors
- Mobile-first responsive
- Tanpa dark mode

## Cara Install

```bash
git clone https://github.com/vioku/vio-quran.git
cd vio-quran
npm install
npm run dev
```

Akses di `http://localhost:5173/vio-quran/`

## Build & Deploy

```bash
npm run build
npm run deploy
```
